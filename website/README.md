# SSHYard website

The official site, generated by `build.py` into static files (`_site/`) and
deployed to GitHub Pages by `.github/workflows/website.yml`.

Every page is rendered at build time from Jinja templates and the language
catalogs, so the HTML that crawlers and link previews receive is complete.
JavaScript only adds interaction (theme switch, the demo window, the
download button for the visitor's platform, the language redirect).

## Layout

| Path | Contents |
| --- | --- |
| `build.py` | The generator: pages, OG images, sitemap, robots, `llms.txt`, icons |
| `og.py` | 1200×630 OG images, drawn with Source Han Sans |
| `templates/` | `base.html`, page templates and `site.css` (rendered through Jinja) |
| `static/site.js` | All client-side behaviour, no dependencies |
| `i18n/*.json` | One catalog per language; `en.json` is the reference shape |
| `icons/` | Extra Remix Icon v4.8.0 SVGs the app itself does not use |

The site also reads from the repository: `internal/icons/svg` (Remix Icon),
`internal/aibrands/png` (LobeHub AI brand icons), `docs/*.webp`
(screenshots), `resources/icon.png` and `mygo.json`.

## Build and preview

```sh
pip install -r website/requirements.txt
python3 website/build.py --serve          # http://127.0.0.1:8000
python3 website/build.py                  # writes website/_site
```

Options: `--base-url URL` (or `SITE_URL`), `--out DIR`, `--release FILE`
(a saved GitHub release JSON instead of fetching the latest), `--strict` (fail instead of falling back when the GitHub
release cannot be read), `--no-og` (skip OG images for a faster build).

Release data (version, date, asset names and sizes) comes from the GitHub
API at build time; set `GITHUB_TOKEN` or `GH_TOKEN` to avoid rate limits.
Without network access the build falls back to `mygo.json`'s version and
the predictable asset names.

The first build downloads the four regional Source Han Sans subsets
(SIL Open Font License 1.1) pinned to one upstream commit, checks their
SHA-256 and caches them in `website/.cache/fonts`.

## Languages

`en` (served at `/`, also `x-default`), `zh-Hans`, `zh-Hant`, `ja` and `ko`.

A visitor arriving from outside the site on an English page is sent, before
anything paints, to the same page in the language they picked before
(`localStorage` `sshyard-lang`), else in their browser's language. GitHub
Pages can't answer with an HTTP 302, so this is `location.replace()` in the
`<head>` of `base.html`, which leaves no history entry. Links within the
site, crawlers and the other languages' URLs are never redirected; those
show a banner suggesting the visitor's language instead.

The build fails if any catalog misses a key, has a different list length or
different `{placeholders}` from `en.json`. Use the app's own terminology
from `locales/*.json`. In CJK headings, `​` marks where a line may wrap
and ` ` keeps words together; both are stripped from the Markdown and
`llms` output.

## Deploy

1. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. The workflow deploys automatically on pushes to `main` that touch the
   site's sources (`website/**`, the screenshots, icons and `mygo.json`),
   after the Release workflow succeeds, when a release is published by
   hand, and on demand (Actions → Website → Run workflow).
3. The workflow only runs once `.github/workflows/website.yml` is on `main`
   (`workflow_run` triggers are read from the default branch).

Optional repository variables:

| Variable | Effect |
| --- | --- |
| `SITE_URL` | Absolute URL of a custom domain, if Pages does not report it |
| `GOOGLE_SITE_VERIFICATION`, `BING_SITE_VERIFICATION`, `BAIDU_SITE_VERIFICATION`, `NAVER_SITE_VERIFICATION`, `YANDEX_SITE_VERIFICATION` | Ownership `<meta>` tags |
| `INDEXNOW_KEY` | Publishes the IndexNow key file and pings IndexNow after each deploy |

`robots.txt` is only honoured at the root of a host. On the default
`licoy.github.io/sshyard` address, crawlers read `licoy.github.io/robots.txt`
instead, so submit `sitemap.xml` in each search console, or use a custom
domain.
